# 试玩记录（方案 11.7「试玩」）

两局，每局不少于 150 回合：

- **顺局**：顺着原著的路走（跟着段公子下山、去神农帮、替人送信或旁观、到万劫谷报信……）。
- **逆局**：存心反着来：抢先取走帛卷、向左掌门告发私情、拜师、远走他乡。

每局开一份记录，复制下面的模板。回合号、游戏内时刻照 `/debug` 或界面抬头填。存档名记下来，出了问题好复现。

## 五个问题

每局结束后逐题作答。前四题答「是 / 大体是 / 否」并举出回合号作证；第五题的答案必须是「没有」，答「有」就是缺陷，要写明回合号、当时的局面和你觉得被拉回去的那件事，交给开发处理。

1. **三个选项里是否总有一个你想选？** 记下所有「三个都不想选、只好自己打字」的回合。
2. **你不在的时候世界是否也在动？** 记下你事后才听说、或回到某地发现变了样的事（谁走了、谁被擒、东西不见了）。
3. **人物是否像他自己？** 记下最像与最不像的各三处：谁、在哪一回合、做了或说了什么。
4. **你的选择是否真的改变了后来的事？** 对照 `/年谱` 的「与原著的分岔」，记下哪些分岔是你引起的，起因是哪一回合。
5. **有没有哪一刻觉得世界在把你往原著拉？** 必须是「没有」。
