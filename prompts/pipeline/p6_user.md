## 任务：P6 文风

填两样：

1. `guide_md`：文风要点，Markdown，全部用自己的话写，不引原文。以下面现有的要点为底，对照原文修订：叙述、对话、打斗、景物各怎么写，称谓怎样合乎身份，哪些写法要避开。给叙述的模型看，所以要具体、可照做。
2. `samples`：按场面类型挑原文短例，每类 {{ min }} 到 {{ max }} 条。`scene` 取：{{ scenes | join('、') }}；`text` 逐字照抄原文里连续的一段（一两句到一小段，不超过 {{ max_len }} 字），`para` 写段落编号。挑最能显出这部书笔法的，避开大段剧情交代。对不上原文的会被丢掉。

现有的文风要点：

```markdown
{{ guide if guide else '（空）' }}
```
